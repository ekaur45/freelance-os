# Node.js

## Overview

Node.js is one of my primary backend platforms for building scalable, high-performance server-side applications. I use it to develop REST APIs, real-time applications, SaaS platforms, microservices, automation tools, AI-powered applications, and backend services.

I primarily work with Node.js using TypeScript and modern frameworks such as NestJS and Express.js, following best practices for maintainability, scalability, and clean architecture.
