# Best Practices

When using C#, I aim to:

* Write readable and maintainable code.
* Follow SOLID principles.
* Prefer dependency injection over tight coupling.
* Handle exceptions appropriately.
* Use asynchronous programming where beneficial.
* Write reusable components.
* Keep business logic separated from infrastructure concerns.
* Optimize database access to reduce unnecessary queries.
