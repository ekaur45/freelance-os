# Best Practices

* Keep views thin; move business logic into services or model methods.
* Use select_related/prefetch_related to avoid N+1 queries.
* Validate requests using DRF Serializers.
* Use Django Admin for internal tooling instead of building custom panels from scratch.
* Offload long-running tasks to Celery.
* Use environment configuration for secrets and settings.
* Write reusable, testable code.
* Follow Django's conventions for maintainability.
