# Entity Framework Core

## Overview

Entity Framework Core (EF Core) is my primary Object-Relational Mapper (ORM) for building data-driven applications with .NET. I use it to design, query, and maintain relational databases while keeping application code clean, maintainable, and performant.

I leverage EF Core in enterprise applications, SaaS platforms, healthcare systems, and business applications where reliable data access, maintainability, and scalability are essential.

# Best Practices

* Keep queries efficient.
* Project only required data.
* Avoid unnecessary Includes.
* Use AsNoTracking() for read-only operations.
* Apply indexes where appropriate.
* Keep DbContext lifetime short.
* Use transactions for critical operations.
* Avoid business logic inside entities.
* Monitor generated SQL for performance.
* Prefer asynchronous database operations.
