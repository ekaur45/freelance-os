# Flask

## Overview

Flask is one of my primary backend frameworks for building lightweight, fast, and flexible web applications and APIs using Python. I use Flask for custom backend development, microservices, AI/ML service endpoints, MVPs, and integration-focused projects where flexibility and minimal overhead are essential.

While I often choose Django for larger, admin-heavy applications, Flask remains my preferred choice for lightweight services, AI inference APIs, microservices, and rapid prototyping.

# Comparison with Django

Choose Flask when

* A lightweight framework is sufficient.
* Building AI/ML model-serving endpoints or microservices.
* Rapid MVP development is required.
* Minimal framework overhead is preferred.

Choose Django when

* Building large, admin-heavy applications.
* Strong built-in conventions and ORM are beneficial.
* The application requires a full-featured admin interface.
* Complex business domains require better organization out of the box.

---

# Notes for AI

Flask should be highlighted whenever clients require lightweight Python backend development, REST APIs, AI/ML model-serving endpoints, microservices, or startup MVPs. If the project is admin-heavy or requires extensive built-in tooling, pair Flask experience with Django knowledge and explain that the framework choice depends on project requirements rather than personal preference.
