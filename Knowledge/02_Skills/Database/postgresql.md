# Best Practices

* Design normalized schemas where appropriate.
* Use JSONB only when it provides clear benefits.
* Optimize indexes based on query patterns.
* Analyze execution plans before tuning.
* Use transactions to maintain data consistency.
* Prefer UUIDs when distributed systems require them.
* Keep migrations version-controlled.
* Monitor slow queries in production.
* Apply proper constraints to enforce data integrity.
* Document complex SQL for maintainability.
