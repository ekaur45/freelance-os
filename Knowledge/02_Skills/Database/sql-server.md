* Design normalized schemas where appropriate.
* Use indexing strategically.
* Analyze execution plans before optimizing.
* Parameterize queries.
* Avoid unnecessary SELECT * statements.
* Use transactions carefully.
* Implement proper error handling.
* Regularly review index usage.
* Optimize queries before scaling hardware.
* Keep database logic maintainable and well-documented.
