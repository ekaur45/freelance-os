# Redis

## Overview

Redis is one of my primary in-memory data stores used to improve application performance, scalability, and responsiveness. I use Redis for distributed caching, session management, rate limiting, background job coordination, real-time data storage, and performance optimization in modern backend applications.

I integrate Redis with .NET, ASP.NET Core, Node.js, NestJS, and cloud-native architectures to reduce database load and improve user experience.

# Best Practices

* Cache only data that provides measurable value.
* Define appropriate expiration policies.
* Avoid caching sensitive information unless properly protected.
* Design cache keys consistently.
* Monitor cache hit and miss ratios.
* Handle cache failures gracefully.
* Prevent cache stampedes where applicable.
* Keep Redis focused on fast-access workloads.
* Invalidate cached data when underlying records change.
* Document caching strategies for maintainability.
