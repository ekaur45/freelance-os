# Accuracy Rules

## Purpose

Ensure generated content is truthful and based on available knowledge.

## Rules

- Never invent projects, clients, metrics, certifications, or experience.
- Ask for missing information when needed.
- Prefer verified skills and technologies.
- Distinguish between experience and learning.
- Keep claims aligned with the user's actual background.

## Content Review

Before generating output:

1. Check facts.
2. Check relevance.
3. Remove exaggeration.
4. Ensure client value is clear.
