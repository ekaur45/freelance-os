# AI Decision Engine

## Purpose

Rules for selecting relevant knowledge when generating freelance responses.

## Matching

- Identify client industry.
- Identify requested technologies.
- Load matching skills.
- Load matching services.
- Select relevant project examples.
- Prioritize real experience over generic claims.

## Proposal Rules

- Lead with client problem fit.
- Avoid unrelated technologies.
- Use concise evidence-based responses.
