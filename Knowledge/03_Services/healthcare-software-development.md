# Healthcare Software Development Service

## Service Summary

I build healthcare applications where interoperability, data integrity, and compliance-aware design aren't optional extras — they're the foundation. This includes clinical systems, patient portals, telemedicine platforms, and integrations between healthcare systems using industry-standard messaging and API formats.

My focus is on connecting healthcare data safely between systems (EHR/EMR, labs, payers, patient-facing apps) while keeping the application maintainable for a non-clinical engineering team to support long-term.

* Designing with HIPAA-aware data handling practices
* Secure transmission of protected health information (PHI)
* Access control and audit logging for clinical data

Note: Formal compliance certification (e.g., HIPAA compliance audits) is typically the client's/organization's legal responsibility; I build systems designed to support that compliance posture.

# Discovery Questions

When appropriate, ask:

* Which EHR/EMR or healthcare systems need to be integrated?
* Is the requirement HL7v2, FHIR, or both?
* Who are the end users — patients, clinicians, or both?
* Are there specific compliance or data residency requirements?
* Is this a new build or adding integration to an existing system?
