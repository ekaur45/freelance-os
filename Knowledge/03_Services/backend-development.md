# Backend Development Service

## Service Summary

I design and build scalable, secure backend systems that power web applications, SaaS platforms, and enterprise software. My focus is on business logic that's correct, APIs that are easy to consume, and architecture that stays maintainable as the product grows — not just code that runs.

I work primarily in .NET and Node.js, with additional depth in PHP (Laravel) and Python (Django/Flask), so the technology choice is driven by the client's existing stack or long-term hiring plans rather than my own preference.

# Discovery Questions

When appropriate, ask:

* What does the backend need to do that it doesn't do today?
* Is this a new build or an existing codebase?
* What's the expected user/traffic scale?
* Are there existing integrations that must be preserved?
* Who consumes the API — a web app, mobile app, or third parties?
* What are the authentication and permission requirements?
