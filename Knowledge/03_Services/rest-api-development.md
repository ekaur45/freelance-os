Whether building a new API from scratch, modernizing an existing backend, integrating third-party services, or improving performance, I focus on creating reliable, scalable, and maintainable solutions that support long-term business growth.

# Discovery Questions

When appropriate, ask:

* Is this a new API or an existing system?
* What clients will consume the API (web, mobile, third-party)?
* Do you already have a database design?
* Which authentication method do you prefer?
* Are there external APIs that need to be integrated?
* What are the expected performance or scalability requirements?
* Is API documentation required?
* Will deployment be part of the project?
